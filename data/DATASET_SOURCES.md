# Dataset sources

PlantVillage is an open plant-health image dataset with 38 classes across 14 plant species. The standardized repository documents CC BY 3.0. It includes Peach and Strawberry, but not all crops requested here.

PlantDoc is a field-image plant disease dataset. The standardized repository documents CC BY 4.0. It can improve real-world backgrounds but does not cover every requested crop.

Only add Mango, Rice, Wheat, Banana, Cotton, Papaya, Guava, Onion, Cabbage, Chilli, Brinjal, Groundnut, Sunflower and Tea images from sources whose license/permission permits your intended use. Record every source in `data/source_manifest.csv`.

Do not scrape random search-engine images with unknown rights.

Treatment text in this project uses registration/label guidance by default. Before publishing pesticide recommendations in India, verify current crop/disease registration, dose, PHI and local agricultural-extension guidance.
